# Pre-Submission Checklist — Physics Manuscript

Run top to bottom. The order matters: structural problems make sentence-level polish worthless.

## 1. The claim

- [ ] The paper's claim can be written as one declarative sentence containing a number
- [ ] That claim appears in the title, the abstract, and the conclusions, consistently
- [ ] Novelty is demonstrated by explicit comparison to the best prior value/method/bound, not asserted
- [ ] The claim is matched to the venue's scope and selectivity criteria

## 2. Venue compliance

- [ ] Current author guidelines fetched and read (not assumed from memory)
- [ ] Word count / page count within limit, measured on the compiled two-column PDF
- [ ] Abstract within limit — **characters, not words, at PRL (600 including spaces)**
- [ ] Correct class file and current version (REVTeX 4.2 / AASTeX v7 / iopart / …)
- [ ] Reference style matches the journal (numbered vs. author–year)
- [ ] Required statements present: data availability, code availability, author contributions,
      competing interests, funding, ethics/facility acknowledgments as applicable
- [ ] Article type is one the journal actually publishes

## 3. Structure

- [ ] Introduction builds a gap rather than reviewing the field; gap type is identifiable
- [ ] Result and its number appear in the introduction, not withheld
- [ ] Methods sufficient for a competent stranger to reproduce the work
- [ ] Results quantify and compare rather than narrating figures
- [ ] Discussion names and eliminates the two leading alternative explanations
- [ ] Limitations stated with bounds, not as vague apologies
- [ ] Conclusions add significance, not a repeat of results
- [ ] Material correctly allocated between main text, End Matter/appendices, and Supplemental Material

## 4. Numbers

- [ ] Every quoted value has a unit (or is explicitly dimensionless) and an uncertainty
- [ ] Significant figures match uncertainty; uncertainty rounded to 1–2 sig figs
- [ ] Statistical and systematic uncertainties separated where both exist
- [ ] Systematic budget itemized with estimation method
- [ ] Meaning of every uncertainty stated at first use
- [ ] Confidence levels, significance tests, and limit-setting methods named
- [ ] Unit system declared; unit typography correct (roman, spaced, not pluralized)
- [ ] Numbers in text agree with numbers in figures, tables, and abstract

## 5. Equations and notation

- [ ] Every displayed equation punctuated as part of its sentence
- [ ] No sentence begins with a symbol
- [ ] Every symbol defined at or immediately after first use
- [ ] One symbol, one meaning; one meaning, one symbol — across text, equations, figures, tables
- [ ] Variables italic, units roman, vectors consistently bold (or arrows), operators roman
- [ ] Sign, metric, and Fourier conventions stated where they matter
- [ ] Only referenced equations numbered; all cross-references generated, none hand-typed
- [ ] `align` used, not `eqnarray`; wide equations in `widetext`

## 6. Figures and tables

- [ ] Figure sequence tells the story without the text
- [ ] Designed at final printed width; internal fonts 7–9 pt at that size
- [ ] Printed at actual size and checked by eye
- [ ] Panels labeled consistently and referenced correctly in the text
- [ ] Data as markers with error bars; models as lines; distinguishable in grayscale
- [ ] No rainbow colormap; no information encoded by color alone; red/green pairs avoided
- [ ] Axis labels carry quantity and unit in the manuscript's own notation
- [ ] Every caption self-contained and defines what error bars mean
- [ ] Tables: caption above, booktabs rules, units in headers, decimals aligned
- [ ] Comparison-to-prior-work table present if an improvement is claimed
- [ ] Vector PDF/EPS for line art; ≥300 dpi raster for images; fonts embedded
- [ ] Every figure and table cited in the text, in order

## 7. Language

- [ ] Claim verbs calibrated to evidence (no "proves"; "consistent with" ≠ "confirms")
- [ ] Tense consistent per section; figures "show" in present tense
- [ ] Wordiness pass done: nominalizations, throat-clearing, intensifiers, `there is/are` removed
- [ ] Noun stacks reduced to three words or unpacked with prepositions
- [ ] Compound modifiers before nouns hyphenated correctly
- [ ] Articles and countability checked (research/evidence/information/equipment are non-count;
      "data" plural if the journal says so — consistently)
- [ ] Parallelism in lists, comparisons, and headings
- [ ] No comma splices or run-ons; conjunctive adverbs punctuated correctly
- [ ] Capitalization of Fig./Eq./Table/Sec. and of named laws and effects correct
- [ ] Read aloud at least once

## 8. References

- [ ] Every citation verified against the actual source — nothing cited from memory
- [ ] No fabricated DOIs, arXiv identifiers, or page numbers
- [ ] Bibliography built with the publisher's `.bst`, not hand-edited
- [ ] arXiv eprint numbers included where the field expects them
- [ ] Software and datasets cited as references with versions and DOIs
- [ ] Citation density appropriate; no padding, no priority claims resting on a single reference

## 9. Submission package

- [ ] Cover letter: claim, case for the venue, novelty vs. closest prior work, housekeeping
- [ ] Suggested and excluded referees, with professional reasons
- [ ] Supplemental Material organized, captioned, and referenced from specific points in the text
- [ ] arXiv posting decided: primary category, cross-lists, license, plain-text abstract, comments field
- [ ] All authors have seen and approved the final version
- [ ] Anonymization done if the journal uses anonymous or dual-anonymous review
- [ ] Source files, figures at final names, and `.bib` all included and compiling from clean
